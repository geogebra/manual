= Checkbox Tool
:page-en: tools/Checkbox
ifdef::env-github[:imagesdir: /en/modules/ROOT/assets/images]

Activate the tool, then click or tap in the image:16px-Menu_view_graphics.svg.png[Menu view graphics.svg,width=16,height=16]
xref:/Graphics_View.adoc[Graphics View] to create a checkbox that can be used to show or hide one or more objects, or as a condition to trigger other actions.

In the appearing dialog window, enter a _Caption_ in the input box (LaTeX format can be used for captions by enclosing the LaTeX string in $ symbols), then select the objects to be controlled by the checkbox from the drop-down list, or directly in any active _View_.

[NOTE]
====

Checkboxes are the visual representation of a xref:/Boolean_values.adoc[Boolean value].

====
