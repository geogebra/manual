= List of Points Tool
:page-en: tools/List_of_Points
ifdef::env-github[:imagesdir: /en/modules/ROOT/assets/images]

In the image:16px-Menu_view_spreadsheet.svg.png[Menu view spreadsheet.svg,width=16,height=16]
xref:/Spreadsheet_View.adoc[Spreadsheet View], select a set of cells that will form the coordinate pairs across rows or columns and activate the tool.

The appearing dialog window allows you to name the list of points, select whether these points will be free or dependent objects, and choose the assignment method for _x_ and _y_ coordinates: X→Y means that when the selected range has 2 columns, the first column provides the x‑coordinates and the second column provides the y‑coordinates. When the range has 2 rows, the first row provides the x‑coordinates and the second row provides the y‑coordinates. Y→X reverses this assignment.

A preview panel shows the list created with the current settings.
