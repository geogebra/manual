= Dot コマンド
:page-en: commands/Dot
ifdef::env-github[:imagesdir: /ja/modules/ROOT/assets/images]

Dot( <ベクトル または リスト>, <ベクトル または リスト> )::
  2つのベクトル，またはリストの内積（スカラー積）を返す．

[EXAMPLE]
====

`++Dot((1, 3, 2), (0, 3, -2))++` 出力： _5_,　2つのベクトル _(1, 3, 2)_ と __(0, 3, -2)__のスカラー積．

`++Dot({1, 2}, {2, 3})++` 出力； _8_.
====

[NOTE]
====

参照： xref:/commands/Cross.adoc[Cross コマンド].

====
