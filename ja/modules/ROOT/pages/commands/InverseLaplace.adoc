== CAS での書式

InverseLaplace( <関数> )::
  与えられた関数の https://en.wikipedia.org/wiki/Inverse_Laplace_transform[逆ラプラス変換]を返す．

[EXAMPLE]
====

`++ InverseLaplace(1/(1+t^2))++` 出力： stem:[\mathbf{ sin(t)} ].

====

InverseLaplace( <関数>, <変数> )::
  与えられた関数を，指定した変数について逆ラプラス変換した結果を返す．

[EXAMPLE]
====

`++InverseLaplace( exp(- a*b),a)++` 出力： stem:[\mathbf{Dirac(a-b)}]

`++InverseLaplace( exp(- a*b),b)++` 出力： stem:[\mathbf{Dirac(b-a)}]

====


InverseLaplace( <関数>, <変数1>, <変数2> )::
  与えられた関数を，指定した変数1について逆ラプラス変換し，その結果を変数2で表したものを返す．

[EXAMPLE]
====

`++InverseLaplace(1/(1+t^2),t,x) ++` 出力： stem:[\mathbf{sin(x)}]

====

====
