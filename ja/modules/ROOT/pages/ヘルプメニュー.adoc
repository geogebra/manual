= ヘルプメニュー
:page-en: Help_Menu
ifdef::env-github[:imagesdir: /ja/modules/ROOT/assets/images]

[NOTE]
====

以下の4つのメニューは，インターネットにアクセスできる環境でのみ機能する．

====

== image:Empty16x16.png[Empty16x16.png,width=20,height=20] チュートリアル

このメニュー項目を選ぶと，GeoGebraの https://www.geogebra.org/m/enp5zy8z[チュートリアル] がブラウザで表示される．

== image:Empty16x16.png[Empty16x16.png,width=20,height=20] マニュアル

このメニュー項目を選ぶと，xref:index.adoc[GeoGebra のマニュアル] がブラウザで表示される.

== image:20px-Menu-help.svg.png[Menu-help.svg,width=20,height=20] ヘルプ

このメニュー項目を選ぶと， https://help.geogebra.org/hc/ja[ヘルプ・センター] がブラウザで表示される．

== image:Empty16x16.png[Empty16x16.png,width=20,height=20] 問題点を報告

このメニュー項目を選ぶと，ブラウザで https://www.reddit.com/r/geogebra/[GeoGebra
ユーザーフォーラム]が開き，問題点を直接報告できる．

== image:20px-Menu-help-about.svg.png[Menu-help-about.svg,width=20,height=20] このプログラムについて/ライセンス

このメニュー項目を選択すると，GeoGebra のライセンス情報と，プログラミングや翻訳など様々な形で GeoGebra プロジェクトに貢献している方々への謝辞を表示するダイアログが開く．
