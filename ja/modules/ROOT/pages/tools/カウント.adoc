= カウント ツール
:page-en: tools/Count
ifdef::env-github[:imagesdir: /ja/modules/ROOT/assets/images]

このツールはimage:16px-Menu_view_spreadsheet.svg.png[Menu view
spreadsheet.svg,width=16,height=16]xref:/表計算ビュー.adoc[表計算ビュー]でのみ使用できる．使い方は2通りある：

* 目的のセルを選択し，このツールを選択する．その後でセル範囲を指定すると，選択したセルの数が目的のセルに表示される．
* 複数のセルを含む範囲を選択し，ツールを選択する．
** 範囲に複数の行がある場合は，各列のセルの数がその列の下に表示される．行ごとのセルの数を数えたい場合は，[.kcode]##Shift##キーを押しながらツールを選択すると，各行のセルの数が選択したデータの右に表示される．
** 範囲が一行だけの場合は，その行のセルの数が選択したデータの右側の空いているセルに表示される．
